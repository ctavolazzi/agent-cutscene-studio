# Playbook

How films are made in this repo, written down from making Snow, Lamp, Bridge.

| File | What it covers |
|---|---|
| [process.md](process.md) | the stages from plan to final export, what each gate package holds |
| [rules.md](rules.md) | the director's rules, determinism, logging, the commit gate, honest tests |
| [techniques.md](techniques.md) | the PS1 look, cameras and frame specs, camera search, derived details, verify, thumbnails, agents |
| [prompts/new-film.md](prompts/new-film.md) | paste-ready prompt to start a film |
| [prompts/continue-film.md](prompts/continue-film.md) | paste-ready prompt to resume one |
| [prompts/ps1-upgrade.md](prompts/ps1-upgrade.md) | paste-ready prompt to push a film to a true PS1 cutscene look |
| [prompts/sound-blockout.md](prompts/sound-blockout.md) | paste-ready prompt to take a film's sound effects from plan to the blockout render (Sound 0 to 2) |
| [prompts/youtube.md](prompts/youtube.md) | packaging checklist, prompt, and the Snow, Lamp, Bridge description |
| [workflows/](workflows/) | multi-agent Workflow scripts: builders with checkers, reviewers with skeptics, research and critique |

The worked example for all of it is `films/snow-lamp-bridge/`: its `PLAN.md`, `ROADMAP.md`, `BUILD_LOG.md` (every step,
every measurement, every mistake) and `review/round-01` to `round-03`.
